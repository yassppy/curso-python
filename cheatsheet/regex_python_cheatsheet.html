re() vs regex{}

hoja de referencia — Python, clase 04

re: librería estándar
regex: pip install regex

Métodos de re

re.search()primera coincidencia en cualquier partetext = "A1 PEDIDO"re.search(r'\d', text) → '1'
re.match()coincidencia solo al iniciotext = "1A PEDIDO"re.match(r'\d', text) → '1'
re.findall()todas las coincidencias, como listatext = "1A2 PEDIDO"re.findall(r'\d', text) → ['1','2']
re.finditer()iterador de objetos Matchtext = "1A2"re.finditer(r'\d', text) → <iterador>
re.sub()reemplaza coincidenciastext = "1A2"re.sub(r'\d', 'X', text) → 'XAX'
re.split()divide el texto por el patróntext = "A-B-C"re.split(r'-', text) → ['A','B','C']

Clases de caracteres

.cualquier carácter, no salto de líneatext = "cat cot c9t"re.findall(r'c.t', text) → ['cat','cot','c9t']
\.punto literal (escapado)text = "www.ejemplo.com"re.search(r'www\.ejemplo', text) → 'www.ejemplo'
\dun dígito (0–9)text = "clave059"re.findall(r'\d', text) → ['0','5','9']
\wletra, dígito o _text = "a_1!"re.findall(r'\w', text) → ['a','_','1']
\sespacio en blancotext = "hola mundo"re.findall(r'\s', text) → [' ']
\D \W \Slo que NO es \d \w \stext = "a#1"re.findall(r'\D', text) → ['a','#']

Cuantificadores

{n}exactamente n vecestext = "código 123"re.search(r'\d{3}', text) → '123'
{n,m}entre n y m vecestext = "12 123 1234"re.findall(r'\d{2,4}', text) → ['12','123','1234']
+una o más vecestext = "total 7890"re.search(r'\d+', text) → '7890'
*cero o más vecestext = "gato gaato gaaato"re.findall(r'ga*to', text) → ['gato','gaato','gaaato']
?cero o una vez (opcional)text = "color colour"re.findall(r'colou?r', text) → ['color','colour']

Conjuntos y grupos

[abc]cualquiera de estos caracterestext = "casa"re.findall(r'[aeiou]', text) → ['a','a']
[A-Z] [a-z]rango de mayúsculas / minúsculastext = "Hola Mundo"re.findall(r'[A-Z][a-z]+', text) → ['Hola','Mundo']
[^abc]todo excepto estos caracterestext = "a1!b2"re.findall(r'[^0-9]', text) → ['a','!','b']
(abc)grupo de capturatext = "01/12"re.search(r'(\d{2})/(\d{2})', text).groups() → ('01','12')
(?P<n>...)grupo con nombretext = "manzana"re.search(r'(?P<fruta>\w+)', text).group('fruta') → 'manzana'

Anclas y límites

^inicio de la cadenatext = "123 abc"re.match(r'^\d+', text) → '123'
$fin de la cadenatext = "abc 123"re.search(r'\d+$', text) → '123'
\blímite de palabratext = "RUC RUCA"re.findall(r'\bRUC\b', text) → ['RUC']

Exclusivo de regex

(?<=...) con {n,} o + — lookbehind de longitud variable text = "precio 1500 soles"regex.findall(r'(?<=\d{3,})\s*soles', text) → [' soles']
(...){e<=N} — búsqueda difusa, tolera N errores text = "el gerente aprovó"regex.search(r'(aprobó){e<=1}', text).group() → 'aprovó'
\p{L} / \p{Han} — letra de cualquier idioma / solo Han text = "José 田中 Müller"regex.findall(r'\p{L}+', text) → ['José','田中','Müller']
(?P<x>...) repetido — mismo nombre de grupo varias veces text = "manzana, pera, uva"regex.findall(r'(?P<fruta>\w+)', text) → ['manzana','pera','uva']
(?R) — patrón recursivo, para anidados text = "(uno (dos) uno)"regex.search(r'\((?:[^()]|(?R))*\)', text).group() → '(uno (dos) uno)'
overlapped=True — coincidencias solapadas en findall text = "aaaa"regex.findall(r'aa', text, overlapped=True) → ['aa','aa','aa']

re vs regex — mismo problema, dos motores

re — estándar 
import re

texto = "El RUC de la empresa es 20123456789 en el año 2026."

# patrón de 11 dígitos con límite de palabra
ruc = re.search(r'\b\d{11}\b', texto)

if ruc:
    print(ruc.group())
# 20123456789
regex — avanzado 
import regex

# 1. coincidencias solapadas
secuencia = "aaaa"
r = regex.findall(r'aa', secuencia, overlapped=True)
# ['aa', 'aa', 'aa']

# 2. lookbehind de longitud variable — prohibido en re
texto2 = "ID_CLIENTE_A_10293"
id_ = regex.search(r'(?<=ID_CLIENTE_.*_)\d+', texto2)
print(id_.group())
# 10293
Nota: ambos módulos usan raw strings (r'...') para que Python no interprete \d o \b como escapes comunes. En consultas SQL (DuckDB, PostgreSQL) aplica la misma regla.
re — viene con Python. regex — pip install regex, para lookbehind variable, fuzzy matching, Unicode extendido y patrones recursivos.
